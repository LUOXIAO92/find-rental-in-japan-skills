# 轻量交接与结果约定

使用紧凑Markdown，不要求大型JSON、重复系统元数据或逐条操作日志。模板可删去不适用项；保留精确身份、证据范围、负责人和未解决事项。

## 条件档案：主agent → 各角色

复核agent由房源agent创建并获得同一份条件档案。

- 用户目标、输出语言、区域／车站范围、入住时间、通勤目的地与时间口径
- 条件逐项：内容；优先级；硬性／偏好；共通／详情／特殊；核验方法与合格证据
- 费用口径：月预算包含什么；敷金、礼金及其他初期费用的用户阈值；未指定的上限留空
- 用户明确允许的降级、备选和例外及适用条件；未授权的放宽不得加入
- 分类和排序规则、约定覆盖范围；仍待澄清的问题及对排除或推荐的影响

## 收集交接：区域agent → merge resolver

### 范围与覆盖
- 区域／车站、来源及查询链接、查看日期时间（带时区）
- 实际筛选、列表补筛、互补查询、覆盖页码／范围
- 状态：本范围收集完成／部分完成／阻塞；剩余范围及具体原因
- 计数口径：广告数、已辨认独立出租单元数、身份未定数；未知则省略精确数值

### 候选：建筑名 · 房号或临时标识
- 身份：建筑别名；地址；房号；楼层；面积；户型；疑似重复对象与理由
- 广告：来源及刊登方、广告直链；查看时间；页面标注的更新日／入住日分别记录
- 共通事实：房租；管理费／共益费；月合计与计算口径；敷金；礼金；其他已知固定费用
- 共通判定：符合／已知不符／未知；依据；适用的用户例外
- 留待核验：身份、价格冲突、缺失字段、详情／特殊条件线索

## 房源分派：merge resolver提供队列，主agent安排负责人

- 精确目标：一套或少量出租单元的标识、全部广告直链、匹配理由及未决重复关系
- 唯一负责人、条件档案、本次必须解决的问题；列表事实只是线索，需自行检查来源
- 可复用的同栋证据及适用范围；房号、价格、户型、照片、招租状态等仍需逐套确认
- 交付：整套核验结果、独立复核状态和未决事项，交merge resolver；不只返回摘要或链接

## 独立复核输入：房源agent → 自行创建的复核agent

先交要求、事实与来源，不以想得到的结论开场：
- 原始用户条件、例外、排序优先级、既定验证方法及证据标准
- 精确房源身份、归并依据与身份不确定性；已查范围和未查范围
- 逐项事实、来源直链、查看时间及适用范围；必要的图纸、照片定位、查询条件或原文摘录
- 冲突、缺项、已试路径及公开资料的已知边界
- 拟定结论另列供比较，明确区分事实和判断；不要求“确认通过”

## 复核回传：复核agent → 房源agent

- 每项：问题／影响的条件；来源证据及定位；所需动作；当前状态
- 状态可为需修正、已解决、公开证据不足待确认、复核受限；无实质问题也需说明检查范围
- 整体：复核完成／复核完成但仍有待确认项／需修正／复核受限
- 修正后复核受影响部分。明确未知可随本轮复核结束保留，不能伪装为条件通过
- 无独立agent时仅记“仅自查，未独立复核”，不使用上述独立复核完成状态

## 房源结果：房源agent → merge resolver

### 建筑名 · 精确出租单元身份
- 调查状态：已完成本次可执行核验／部分完成／阻塞；已查范围、未查范围及原因
- 复核状态：独立复核的结果、修正摘要与遗留问题；未独立复核时明确标出
- 来源：逐个广告或提供商直链；查看时间；发布／更新／入住日期按来源含义注明
- 当前费用：房租、管理费／共益费、月合计、其他固定月费；敷金、礼金、保证费等已知初期费用及附带条件
- 空间：面积、楼层、户型及证据；室内／户型照片的适用房间，样板间或其他房间照片明确标出
- 通勤：用户目标、出发／到达时间口径、步行与换乘、计算日期及来源；仅在需要时核验
- 特殊条件：分项结论、证据、适用建筑／房间范围；无依据的推测不可写成已确认
- 事实与适配：已证实内容；条件逐项符合／不符／未知；软偏好评价及依据
- 冲突与缺口：矛盾来源、缺失字段、仍需谁确认什么；页面“可入住”不等于实时空室保证
- 建议类别与理由、用户例外是否适用；不能用调查或复核完成覆盖未知硬条件

普通跨来源或跨房源冲突交merge resolver协调负责人补查并复核；改变条件、阈值、验证方法、范围或授权的事项另交主agent决定。进度摘要可同时回报主agent。

## 最终交付：merge resolver维护统一Markdown

用用户选择的语言；未指定时沿用对话语言。先给简短结论与既定排序依据，再给条件、覆盖、统一总表及必要逐套说明，不把多份代理报告原样堆叠。

按主agent下发规则分类，例如“优先／待确认／备选／排除”。硬条件明确不符应排除；只有命中用户明确允许的降级或例外才可列备选。缺证通常进入待确认，不能写成不符合或已满足。

每套保留身份、关键费用与日期、户型／照片、必要通勤与特殊条件结论、适配理由、重要缺口、复核状态和少量直接来源链接。关键结论就近归因；共享同栋事实可集中引用，但逐套身份与结论不能合并掉。

末尾注明核验时间、来源／分页覆盖、未完成范围和具体下一步。去重后未分派及未完成核验的候选不得遗漏，列明排队／未查／暂缓、原因、剩余范围，以及可可靠计数时的数量；这些状态不计作核验完成。区分收集完成、出租单元核验完成、独立复核状态与仍待外部确认。向主agent交付同一份文档及简报，主agent负责面向用户的进度与决策沟通。
