# 工作流程 DAG

## 主agent、merge resolver与房源负责人

```mermaid
flowchart TD
    U[用户条件] --> M[主agent：条件、优先级、验证方法与范围]
    M --> A[收集agent：按网站或区域并行，共通站内筛选再列表补筛]
    M --> D[独立merge resolver：跨区域去重与候选队列]
    A --> D
    D --> S[主agent：按队列分派唯一房源负责人]
    S --> P[房源agent：每人完整核验一套或少量房源]
    P -->|自行创建并交付要求、事实和来源| V[该房源的独立复核agent]
    V --> J{复核发现}
    J -->|可修正问题| R[房源负责人：定向补查与修正]
    R --> V2[同一复核agent：复核受影响部分]
    J -->|证据足够或已达公开资料边界| T[房源负责人：保留结论、未知和复核状态]
    V2 --> T
    T --> H[merge resolver：归并身份、来源与房源结果]
    H --> K{跨报告事实是否一致}
    K -->|普通事实冲突| C[merge resolver：协调相关房源负责人]
    C --> P2[相关负责人：补查并自行安排独立复核]
    P2 --> H2[merge resolver：归并修正或保留未决事实]
    K -->|一致| F[merge resolver：按既定规则分类排序]
    H2 --> F
    F --> O[merge resolver：维护统一文档与状态简报]
    O --> L[主agent：向用户报告结果与待决定事项]
```

网站／区域收集任务之间可并行；完成共通初筛的一批先去重，再启动对应房源的并行完整核验，不必等待所有收集任务。收集和已就绪房源核验可流水并行，收集按批次交接。merge resolver独立维护身份、来源、结果与文档；主agent负责资源和方向。复核agent由对应房源agent创建并向其回传，不由主agent创建来逐套审查。

条件含义、阈值、验证方法、优先级、范围或授权变化才升级主agent；普通事实差异由merge resolver协调房源负责人处理。主agent可依据各角色简报随时向用户报告进度，不需等到图中最终交付。

## 单套房源内部

```mermaid
flowchart TD
    I[房源任务与验证要求] --> A[房源负责人：核对广告、楼栋与房号]
    A --> B{基础条件与有效性}
    B -->|可继续| C[费用、入住与合同核查]
    B -->|可继续| D[说明、户型与室内照片判断]
    B -->|可继续| E[按需核验门到门通勤]
    B -->|可继续| F[按需执行独立专项验证]
    C --> G[房源负责人：整合原始事实与逐项证据]
    D --> G
    E --> G
    F --> G
    B -->|明确不符| H[按用户规则拟列备选或排除，注明未查范围]
    B -->|身份或状态未明| K[补查或保留未知、冲突及所需信息]
    H --> G
    K --> G
    G -->|负责人自行创建| R[独立复核agent：检查要求、身份、证据与判定]
    R --> J{复核结果}
    J -->|有可补查问题| P[房源负责人：补查与修正]
    P --> R2[同一复核agent：复核受影响结论]
    R2 --> N[房源负责人：保留修正、未知及复核状态]
    J -->|无实质问题或公开证据已达边界| N
    N --> O[房源负责人：整套结果交merge resolver]
```

费用、详情、通勤、专项检查没有依赖时可并行，但房源负责人始终负责整套结果。专项分支不等于独立复核。明确未知可以结束本轮复核，未知硬条件不能因此通过；可补查问题未解决或来源受阻时照实标明。用户要求继续检查备选或已排除房源的其他条件时，按授权范围执行。

两图将补查和再次复核展开为前向节点，保持无环。仍需后续补查时继续展开新的修正节点：单套问题由房源负责人跟进，跨房源事实问题由merge resolver协调；只有范围或规则变化需要主agent重新编排。没有独立agent能力时按相同职责自查并明确标“未独立复核”，不把顺序自查冒充图中的独立角色。
