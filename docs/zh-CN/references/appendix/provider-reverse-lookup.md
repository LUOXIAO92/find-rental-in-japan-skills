# 附录：从网络供应商反查出租楼栋

用途：用户有网络条件而普通房源字段过于含糊时，从导入线索反查楼栋，再找当前出租房间。最后核查：2026-10-02；以下核实公开入口和页面说明，未假装完成任何具体楼栋查询。

## 先分清四种主体

- 楼盘品牌／开发商：可缩小候选，但同品牌不同楼栋、不同期次可能采用不同网络。
- 物业／出租管理公司：掌握实际设备、合同与施工许可，不一定是网络服务提供者。
- 网络服务品牌／供应商：可提供楼栋专用页、接线说明或导入案例；全户合同与个人零售产品须区分。
- 底层线路运营商：提供接入网；不能只由其名称推断楼内配线、整栋上联和每户性能。

一条完整证据链至少是：**供应商线索 → 同一楼栋身份 → 本栋实际技术配置 → 当前出租房间**。其中任一项未知，就保留其未知状态。

## 路径 A：先有楼名，查供应商

1. 从房源保存完整设备原文、楼名、地址和房号，不把 `ネット無料` 改写为某供应商。
2. 若已知 UCOM 或 e-mansion，用相应官方楼名查询；按页面允许的方式变换名称，记录每个有效匹配。
3. 若供应商未知，搜索 `"楼名" "町名" インターネット`，再尝试 `回線`、`UCOM`、`e-mansion` 等有依据的线索。管理方募集图、设备说明优于没有来源的论坛推测。
4. 将命中的地址逐项对齐。名称相同但地址不同、同园区不同栋、翻新／改名以前的记录都分开处理。
5. 从专用页取得能公开确认的服务名和接入方式，然后按 [网络附录](fiber-reference.md) 补本房间状态与用户关心的性能事实。

## 路径 B：先有供应商，找楼，再找房

收集agent执行本路径时，只把发现的出租房间做通用条件站内初筛和列表补筛，再交merge resolver去重；去重后由分派的房源负责人完成详细技术核验及全部硬条件检查。收集阶段下列技术字段能取得多少就回传多少，其余标为线索或未知，不在去重前逐广告深查。

1. 选与用户条件相关的供网方案，不把某品牌设成默认通过。使用公开导入案例或允许的楼名部分搜索；若只有匿名案例，就从服务名关键词搜索募集资料。
2. 组合例子（尖括号为待替换条件，不是实际楼栋）：
   - `"UCOM光 レジデンス" "<区域>" 賃貸`
   - `"e-mansion" "<车站或町名>" 賃貸`
   - `"B-CUBIC" "<市区>" 賃貸`
   - `site:eheya.net/detail/ "DK SELECTネットサービス" "NURO" "<区域>"`
   - `"NURO 光 Connect" "<区域>" 賃貸`
3. 搜索引擎摘要只生成线索；打开募集详情，记录完整设备名称及后缀。`DK SELECTネットサービス` 本身不足以证明 NURO，省略括号或后缀可能把不同配置混在一起。
4. 以楼名＋地址去重，将每栋送至 [常用房源入口](housing-sites.md) 找当前出租住户。只在互联网服务目录里出现的楼，仍然不是出租房源。
5. 在当前募集房间上核实费用、户型、面积、入居日期和全部其他硬条件；网络合适也不能豁免这些核验。
6. 若无当前空室，保留为后备楼栋线索；不未经请求建立长期监控。若有空室但技术证据不足，保留候选并列出具体缺项。

## 三类常见误判

- **单独零售覆盖 ≠ 全户网络身份**：NTT／NURO／au 的零售地址查询回答该零售产品能否提供。NURO零售查询没有集合住宅结果，不能因此否定该栋的 NURO 光 Connect 或其他全户产品；零售另装线索也不证明已安装。
- **服务品牌 ≠ 结构合格**：同品牌可能有 LAN、FTTH、不同上联和不同改造批次。反查仅提高找到可核验房源的效率，不能替代技术证据。
- **未命中 ≠ 未导入**：别名、公开范围、目录时效、文字编码和系统结果上限都可能造成漏检。区分“确认没有”和“公开入口未找到”。

## 回传最小证据包

- 当前出租详情 URL、查看日期、房号或暂定房间身份
- 楼名及别名、完整地址、栋号；如何对齐不同来源
- 供应商／产品全称、官方查询入口、输入条件和结果范围
- 本栋配置来源、适用日期；哪些是品牌通用说明，哪些是本栋／本房间确认
- 到户介质、状态、套餐上下行、用户要求的共享信息，以及仍缺的证明
- 结论：仅线索／网络待确认／满足本次网络条件；随后由房源负责人并入整体房源判定

公开查询足够时不注册、不冒充住户；遇到登录或需联系管理方时交回负责人处理授权。住户专用页中的登录凭据、密钥和个人信息不得进入研究材料。

## 东京都内的补充参考资料

用户指定的补充参考站点为[マンションdeネット 東京](https://mansionnet-tokyo.sakura.ne.jp/)。核查日期：2026-10-02。首页提供公寓名／地址搜索、东京23区分区列表及按回线品牌浏览的入口。网站说明其选择性收录东京都内的部分楼栋，包括多摩地区。

在东京都内查找楼名和可用回线线索时，将其作为补充参考。先核对楼名＋地址，再检查官方查询入口及当前募集详情。站点记录不能替代官方配线核验，也不能证明本房间的回线可用性或当前空室状态。
