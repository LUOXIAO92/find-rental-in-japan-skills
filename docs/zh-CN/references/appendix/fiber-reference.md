# 附录：住宅网络事实与官方查询

用途：为 [住宅网络核验](../internet.md) 提供术语、官方入口和取证方法，不预设本次用户的通过阈值。最后核查：2026-10-02。以下核实了公开入口和技术说明，没有对任意地址完成覆盖查询；实际任务必须留下本次地址、楼栋／房间和结果证据。

## 到户介质与实际判断

| 名称 | 指什么 | 有价值的本房间证据 | 不能由此推断 |
| --- | --- | --- | --- |
| FTTH／光配線方式 | 光纤进入住户，由 ONU 等终端接入 | 精确楼栋查询显示对应光配线产品；房间光插座及 ONU 信息；运营商／管理方对实际布线的说明 | 光纤到户不等于独享局端、楼栋外联或互联网带宽；有插座不等于线路已开通、可复用或属于目标运营商 |
| LAN配線方式 | 共用设备至住户为以太网线 | 本栋网络图、交换设备与端口规格、住户接入说明 | 墙上 LAN 口可能只是室内布线，须追踪其上游；LAN 不自动等于 100M，也不自动等于整栋只有 1G |
| VDSL／电话线方式 | 楼内最后一段使用电话铜线，并有相应设备 | 精确套餐／配线方式、VDSL 装置型号及接线说明 | “光回线”可只描述楼外至共用部；不要把其他铜线技术如 G.fast 的速率照搬为 VDSL 速率 |
| CATV／HFC／同轴 | 网络最后一段可能经同轴与 cable modem 接入 | 完整网络产品名、提供类型、实际 modem 与布线 | CATV 公司也能提供 FTTH；“有 CATV”可能仅指电视。不能按公司名字或电视同轴端子判定网络介质 |
| 埋込 Wi-Fi／免费 Wi-Fi | 描述无线接入点或使用方式 | AP 的上游接线、供网服务名、房间／共用部安装范围 | Wi-Fi 版本不说明楼外带宽、到户介质或是否有可用有线端口 |

官方技术依据：
- NTT 东日本 [集合住宅光配线施工](https://flets.com/navigation/kouji/multi_unit.html)、[LAN 方式](https://flets.com/navigation/kouji/const_apartment_lan.html)、[VDSL 方式](https://flets.com/navigation/kouji/const_apartment_vdsl.html)：解释共用部至住户的连接差别，并明确存在共同利用结构。
- NTT 东日本 [从区域查询结果识别配线方式](https://flets.com/assets/html/att_flets_mntype.html)：读取查询返回的实际菜单后再对照；不凭“フレッツ対応”判断。
- J:COM [光回线与有线电视回线说明](https://www.jcom.co.jp/service/net/column/005.html)：同一供应商可有光回线与光混合方式，须核对目标产品。

## 官方可提供查询入口

这些入口用于只读查覆盖／产品。到“申请、回电、资料寄送、账户注册”等环节应停止，除非已取得相应授权。不要为了得到查询结果假填身份资料。

| 官方入口与页面路径 | 输入 | 应保存的输出 | 结果限制 |
| --- | --- | --- | --- |
| [NTT东日本：提供エリア検索](https://flets.com/flets-hikari/application/sim/)；首页也有邮编／都道县入口 | 邮编或地域，逐级到番地、住宅类型、楼名；按界面选择具体对象 | 完整匹配地址／楼名、服务菜单、配线方式或其判读依据、待调查提示 | 覆盖、可申请、已安装不是同一状态；只有地区覆盖不足以证明本栋。光コラボ可另用官方[光接入区域查询](https://flets.com/app2/search_c.html)，再核对目标零售服务 |
| [NTT西日本：申请／区域确认导航](https://flets-w.com/navigation/) → 新規お申し込み／提供エリア確認 | 目标地址、住宅类型、具体建筑；以当前表单为准 | 提供可否、适用产品、设备调查或等待提示 | 导航入口已核实；没有完成动态地址流程。官方[光ネクスト说明](https://flets-w.com/service/next/)明确区域内仍可能受设备限制 |
| [NURO 光官方首页](https://www.nuro.jp/) → 提供エリア確認・お申し込み，选择集合住宅 | 邮编、地址、住宅类型／楼栋，按当前流程补齐 | 当前准确产品和提供类型、楼栋匹配、设备／施工提示 | 旧 `/hikari/` 本次跳转首页；不要固定沿用旧产品名、2G或旧价格。零售查询未收录不能否定 NURO 光 Connect 等整栋合同；另装可申请也不证明已有整栋服务 |
| [auひかり マンション](https://www.au.com/internet/mansion/) → 提供エリアの確認 | 地址和目标楼栋 | 本栋准确タイプ、配线与上下行说明、可申请条件 | au 同品牌存在多种到户方式，不能仅凭“auひかり”判 FTTH。必须对照结果对应产品；不要把首页其他产品套给本栋 |
| [J:COM网络官方入口](https://www.jcom.co.jp/service/net/) → 料金シミュレーション／対応エリア・物件 | 地区／地址和住宅类型，依当前流程选择楼栋 | 对应产品全称、提供方式、免费部分及付费升级的区别 | 入口已核实，动态结果未实测；必须分清光、光混合、电视支持和本房间可用网络 |

入口内容会变化。动态页面无法读取时，先在可用浏览器继续官方公开流程；若仍被登录、验证码、错误或资料要求挡住，写明卡在什么步骤，不伪造“未覆盖”。保留稳定入口＋选择路径＋查询时间；会话 URL 可能不能复现，必要时另存截图和原文摘录。

## 把“光纤可用”拆成可核查事实

1. **对象**：邮编、地址、楼名及别名、栋号、房号，查询匹配到哪一层。近邻楼和同品牌楼不能代替。
2. **状态**：区域覆盖 → 本栋产品可申请 → 本房间具备线路／端口 → 可复用或需施工 → 已开通。只记录证据实际到达的阶段。
3. **施工**：管理方允许的引入路径、共用部作业、打孔／原状恢复要求，运营商是否有端口和可约工期。覆盖查询不授权施工，也不保证入住前开通。
4. **速率**：分别记录套餐上下行、端口限制、尽力而为条款和用户实际关心的上传／流量限制。`最大1Gbps` 不等于持续实测 1Gbps。
5. **共享层级**：分开记录每户端口／套餐、楼内交换机上联、楼栋外联及接入网 PON 共享。不要把“一户一 ONU”“单独签约”“有偿”或“光配线”改写成带宽独享。
6. **体验**：有线测试的时间、设备、目标线路及测速端点可作补证；另一住户或另一时间测速不能保证此房的晚高峰吞吐、抖动和丢包。

用户若只排斥某一层级的共享，按其定义判定；不能自动升级为要求互联网全程专线。若关键信息没有公开，记未知而非通过或失败。

## 实用补证问题

根据缺项挑选，交房源负责人决定是否需获准向管理方／供应商询问：
- 「この部屋までの配線は光ファイバー・LAN・電話線・同軸のどれですか。現在のサービス名とプラン名も教えてください。」
- 「建物全体の上位回線容量と各戸ポートの上限は別々に何Gbpsですか。共有範囲を確認できる資料はありますか。」
- 「この部屋に回線・光コンセント・ONUは残っていますか。再利用の可否と開通に必要な工事は確認済みですか。」
- 「別回線の新規引込みは可能ですか。管理側の許可条件と共用部の工事制限を教えてください。」

不要索要住户密码、Wi-Fi密钥、账户或其他住户的身份资料。回传采用 [共同格式](../contracts.md)，附结论适用范围、直接来源、查询日和未决项。
