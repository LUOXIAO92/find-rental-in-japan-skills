# 付録　住宅インターネットの事実と公式照会

[住宅インターネットの検証](../internet.md)で使う用語、公式窓口、根拠の集め方をまとめる。この付録で、今回のユーザーの合格基準をあらかじめ定めることはしない。

最終確認は2026-10-02。公開窓口と技術説明は確認したが、いずれの住所についても提供可否の照会は完了していない。実際の調査では、対象の住所、建物／部屋、照会結果の根拠を残す。

## 各戸までの配線媒体を確認する

| 名称 | 意味 | この部屋の確認に役立つ根拠 | そこからは判断できないこと |
| --- | --- | --- | --- |
| FTTH／光配線方式 | 光ファイバーが住戸まで入り、ONUなどの端末で接続する | 建物を正確に指定した照会で、該当する光配線の商品が表示されること。室内の光コンセントとONUの情報。事業者／管理側による実際の配線の説明 | 各戸まで光ファイバーがあることは、局側設備、建物の外部接続、インターネット帯域の専有を意味しない。コンセントがあっても、回線が開通済み、再利用可能、または対象事業者のものとは限らない |
| LAN配線方式 | 共用設備から住戸まではイーサネットケーブルを使う | この建物のネットワーク図、スイッチ設備とポートの仕様、住戸の接続説明 | 壁のLANポートは室内配線だけの場合もあるため、上流をたどる必要がある。LANだからといって100Mとは限らず、建物全体で1Gしかないとも限らない |
| VDSL／電話線方式 | 建物内の最後の区間に電話用の銅線を使い、対応する設備がある | 正確なプラン／配線方式、VDSL装置の型番と配線説明 | 「光回線」は建物外から共用部までだけを指す場合がある。G.fastなど他の銅線技術の速度をVDSLの速度として流用しない |
| CATV／HFC／同軸 | ネットワークの最後の区間を、同軸とケーブルモデムで接続する場合がある | インターネット商品の正式名称、提供タイプ、実際のモデムと配線 | CATV会社もFTTHを提供できる。「CATVあり」はテレビだけを指す場合もある。会社名やテレビ用の同軸端子でインターネットの配線媒体を判断しない |
| 埋込Wi-Fi／無料Wi-Fi | 無線アクセスポイントまたは利用方法を表す | APの上流の配線、インターネットサービス名、室内／共用部の設置範囲 | Wi-Fiのバージョンからは、建物外の帯域、各戸までの配線媒体、利用可能な有線ポートの有無は分からない |

### 技術的な根拠となる公式資料

- NTT東日本の[集合住宅の光配線工事](https://flets.com/navigation/kouji/multi_unit.html)、[LAN方式](https://flets.com/navigation/kouji/const_apartment_lan.html)、[VDSL方式](https://flets.com/navigation/kouji/const_apartment_vdsl.html)。共用部から住戸までの接続の違いと、共同利用する構造を説明している。
- NTT東日本の[エリア検索結果から配線方式を識別する](https://flets.com/assets/html/att_flets_mntype.html)。照会結果に表示された実際のメニューを読み、資料と照合する。「フレッツ対応」だけで判断しない。
- J:COMの[光回線とケーブルテレビ回線の説明](https://www.jcom.co.jp/service/net/column/005.html)。同じ提供事業者に光回線と光ハイブリッド方式があるため、対象商品を確認する必要がある。

## 公式窓口で提供可否を照会する

以下の窓口は、提供エリアと商品を読み取り専用で照会するために使う。申し込み、折り返し電話、資料送付、アカウント登録などに進む場合は、対応する許可がなければ停止する。照会結果を得るために架空の本人情報を入力しない。

| 公式窓口とページ上の経路 | 入力 | 保存する照会結果 | 結果の限界 |
| --- | --- | --- | --- |
| [NTT東日本の提供エリア検索](https://flets.com/flets-hikari/application/sim/)。トップページにも郵便番号／都道府県からの入口がある | 郵便番号または地域から、番地、住宅タイプ、建物名まで順に指定する。画面に従い、具体的な対象を選ぶ | 一致した住所／建物名の全体、サービスメニュー、配線方式またはその判読根拠、要調査の案内 | エリア内、申し込み可能、設置済みは同じ状態ではない。地域がエリア内であるだけでは、この建物での提供を証明できない。光コラボは別途、公式の[光アクセスエリア検索](https://flets.com/app2/search_c.html)を使い、その後に対象の小売サービスを確認することもできる |
| [NTT西日本の申し込み／エリア確認ナビゲーション](https://flets-w.com/navigation/) → 新規お申し込み／提供エリア確認 | 現在のフォームに従い、対象住所、住宅タイプ、具体的な建物を入力する | 提供可否、適用商品、設備調査や待機の案内 | ナビゲーションの入口は確認済みだが、動的な住所入力フローは完了していない。公式の[光ネクストの説明](https://flets-w.com/service/next/)には、エリア内でも設備による制限があり得ると明記されている |
| [NURO 光公式トップページ](https://www.nuro.jp/) → 提供エリア確認・お申し込みで集合住宅を選択 | 現在のフローに従い、郵便番号、住所、住宅タイプ／建物を入力する | 現在の正確な商品と提供タイプ、建物の一致、設備／工事の案内 | 旧`/hikari/`は今回トップページに転送された。古い商品名、2G、旧料金を固定的に使い続けない。小売向けの検索に未収録でも、NURO 光 Connectなどの全戸契約は否定できない。別途設置を申し込めても、全戸向けサービスが既にある証明にはならない |
| [auひかり マンション](https://www.au.com/internet/mansion/) → 提供エリアの確認 | 住所と対象の建物 | この建物の正確なタイプ、配線と上り下りの説明、申し込み条件 | auの同一ブランドにも各戸への接続方式が複数ある。「auひかり」だけでFTTHとは判断できない。結果に対応する商品と照合し、トップページの他商品をこの建物に当てはめない |
| [J:COMインターネット公式窓口](https://www.jcom.co.jp/service/net/) → 料金シミュレーション／対応エリア・物件 | 地域／住所と住宅タイプを入力し、現在のフローに従って建物を選ぶ | 該当商品の正式名称、提供方式、無料部分と有料アップグレードの違い | 入口は確認済みだが、動的な照会結果は実際に確認していない。光、光ハイブリッド、テレビ対応、この部屋で利用できるインターネットを区別する必要がある |

入口の内容は変わる。動的ページを読み取れない場合は、まず利用可能なブラウザで公式の公開フローを続ける。それでもログイン、CAPTCHA、エラー、情報入力の要求で止まる場合は、止まった段階を明記する。「エリア外」という結果を捏造しない。

安定した入口、選択経路、照会日時を残す。セッションURLだけでは再現できない場合があるため、必要に応じてスクリーンショットと原文の抜粋を別途保存する。

## 「光ファイバー利用可」の根拠を項目ごとに確認する

1. 対象を照合する。郵便番号、住所、建物名と別名、棟番号、部屋番号を記録し、照会ではどの単位まで一致したかを示す。近隣の建物や同ブランドの建物では代用できない。
2. 状態を区別する。地域がエリア内 → この建物で商品を申し込み可能 → この部屋に回線／ポートがある → 再利用可能または工事が必要 → 開通済み。根拠が実際に示す段階だけを記録する。
3. 工事の条件を記録する。管理側が認める引き込み経路、共用部の作業、穴開け／原状回復の条件、事業者側のポートの有無、予約可能な工期を確認する。提供可否の照会は工事を許可するものではなく、入居前の開通も保証しない。
4. 速度に関する情報を分けて記録する。プランの上り下り、ポート制限、ベストエフォートの条項、ユーザーが実際に重視するアップロード／通信量制限を区別する。`最大1Gbps`は、実測で継続的に1Gbps出ることを意味しない。
5. 共有される階層を分けて記録する。各戸のポート／プラン、建物内スイッチのアップリンク、建物の外部接続、アクセス網のPON共有を区別する。「各戸にONU1台」「個別契約」「有料」「光配線」を帯域専有と言い換えない。
6. 実際の使い心地については、有線テストの日時、機器、対象回線、速度測定先が補足の根拠になる。他の住戸や別の時間帯の測定では、この部屋の夜間ピーク時のスループット、ジッター、パケットロスを保証できない。

ユーザーが特定の階層の共有だけを避けたい場合は、その定義に従って判断する。インターネットの全区間で専用線を求める要件に、自動的に引き上げてはならない。重要な情報が公開されていなければ、合格や不合格ではなく不明と記録する。

## 不足する根拠を問い合わせるための質問例

不足項目に応じて質問を選ぶ。管理側／提供事業者への問い合わせに許可が必要かどうかは、物件担当者の判断に委ねる。

- 「この部屋までの配線は光ファイバー・LAN・電話線・同軸のどれですか。現在のサービス名とプラン名も教えてください。」
- 「建物全体の上位回線容量と各戸ポートの上限は、それぞれ何Gbpsですか。共有範囲を確認できる資料はありますか。」
- 「この部屋に回線・光コンセント・ONUは残っていますか。再利用の可否と開通に必要な工事は確認済みですか。」
- 「別回線の新規引き込みは可能ですか。管理側の許可条件と共用部の工事制限を教えてください。」

入居者のパスワード、Wi-Fiキー、アカウント、他の入居者の本人情報を求めない。報告には[共通形式](../contracts.md)を使い、結論の適用範囲、直接の出典、照会日、未解決項目を添える。
